# Kaggle AIMO3 — Dataset Pipeline

This repository contains data and scripts for the [AI Mathematical Olympiad Progress Prize 3](https://www.kaggle.com/competitions/ai-mathematical-olympiad-progress-prize-3) Kaggle competition.

---

## Datasets

### `data/imosl_cleaned.txt` — IMO Shortlist (proof format)

Formatted problems from the **IMO Shortlist** (2006–2023), sourced from [AI-MO/olympiads](https://huggingface.co/datasets/AI-MO/olympiads) on HuggingFace.

| Field | Value |
|---|---|
| Total problems | 1,288 |
| Years covered | 2006 – 2023 |
| With explicit answer | 139 |
| Proof-based (no answer) | 1,149 |

---

### `data/imosl_with_answers.txt` — IMO Shortlist (integer-answer format)

Same problems as above, but proof-based problems have been **automatically reformulated** by Claude into questions with a specific integer answer, without reducing the mathematical difficulty.

For example:
- *"Prove the maximum value of X is k"* → *"What is the maximum value of X?"* → answer: `k`
- *"Prove there are exactly n solutions"* → *"How many solutions are there?"* → answer: `n`

Problems where no natural integer reformulation exists retain an empty `final_answer`.

| Stat | Count |
|---|---|
| Originally with answer | 139 |
| Newly converted by Claude | 124 |
| Total with answer | 263 |
| Remaining proof-only | 1,025 |

Generated by `scripts/reformulate_imosl.py` using the Anthropic Batches API (Claude Sonnet 4.6).

## Format

Both files use the same XML-tag structure:

```
<question_id>imosl_001</question_id>
<category>Algebra</category>
<question>Problem statement in LaTeX</question>
<reasoning>Full solution / proof in LaTeX</reasoning>
<final_answer>Integer answer, or empty for proof-only problems</final_answer>

==================================================
```

- **question_id**: sequential ID `imosl_NNN`
- **category**: `Algebra` | `Combinatorics` | `Geometry` | `Number Theory`
- **question**: problem statement (LaTeX)
- **reasoning**: full official solution (LaTeX)
- **final_answer**: integer answer where available; empty otherwise

## Reproducing

### Step 1 — Download raw data

```bash
python3 -c "
from huggingface_hub import snapshot_download
snapshot_download('AI-MO/olympiads', repo_type='dataset',
    local_dir='data/raw/olympiads',
    allow_patterns=['**/segmented/*.jsonl'])
"
```

### Step 2 — Merge all JSONL files

```bash
python3 -c "
import json, glob
files = glob.glob('data/raw/olympiads/**/segmented/*.jsonl', recursive=True)
with open('data/olympiads_merged.jsonl', 'w') as out:
    for f in files:
        for line in open(f):
            if line.strip(): out.write(line)
"
```

### Step 3 — Format IMO Shortlist (proof format)

```bash
python3 scripts/format_imosl.py
# Output: data/imosl_cleaned.txt
```

### Step 4 — Reformulate into integer-answer format

Requires an Anthropic API key (uses the Batches API at 50% cost):

```bash
export ANTHROPIC_API_KEY=sk-ant-...
python3 scripts/reformulate_imosl.py
# Output: data/imosl_with_answers.txt
```
